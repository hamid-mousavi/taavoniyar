# سامانه مدیریت تعاونی‌های مسکن «مسکن‌یار»
## راهنمای جامع مستندات فنی و عملیاتی (Documentation Index)

این پوشه حاوی مستندات رسمی و کامل سامانه مسکن‌یار برای نقش‌های مختلف و راهنمای استقرار سرور است:

### ۱. راهنماهای نقش‌های کاربری:
- [راهنمای مدیر ارشد سامانه (Super Admin)](./SUPER_ADMIN_GUIDE.md): مدیریت کلان تعاونی‌ها، انتصاب مدیران، نظارت امنیتی و بازیابی سراسری داده‌ها.
- [راهنمای مدیر تعاونی مسکن (Cooperative Manager)](./COOP_ADMIN_GUIDE.md): ثبت اعضا، صدور اقساط ساختمانی، صدور شارژ و هزینه‌های جاری، تسویه با تاریخ شمسی، و داشبورد هوش مصنوعی Groq AI.
- [راهنمای اعضا و خریداران واحد (Member)](./MEMBER_GUIDE.md): پیگیری اقساط، پرداخت آنلاین شتابی شاپرک، ثبت فیش واریزی و دریافت رسیدهای دیجیتال.

### ۲. راهنمای استقرار و زیرساخت داکر:
- [راهنمای استقرار با Docker و PostgreSQL](./DOCKER_DEPLOYMENT.md): نحوه اجرای کانتینر دیتابیس PostgreSQL 16 Alpine، پنل pgAdmin 4 و اپلیکیشن با دستور `docker compose up -d`.

### ۳. دسترسی درون‌برنامه‌ای:
کاربران در هر زمان می‌توانند با کلیک روی تب **«راهنمای سامانه»** در نوار بالای وب‌سایت، به نسخه تعاملی و قابل چاپ این مستندات دسترسی پیدا کنند.
