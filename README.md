# سامانه یکپارچه مدیریت تعاونی‌های مسکن (مسکن‌یار)

سامانه جامع و چندمستأجری (Multi-Tenant) جهت مدیریت پروژه‌ها، اعضا، واحدها، تقویم اقساط، پرداختی‌های آنلاین و آفلاین (فیش بانکی) و اطلاعیه‌های تعاونی‌های مسکن.

---

## ۱. نقش‌های کاربری در سیستم
1. **مدیر کل (Super Admin):** نظارت بر کلیه تعاونی‌ها، گزارش‌های تجمیعی مالی، صدور بخشنامه‌ها و اطلاعیه‌های سراسری.
2. **مدیر تعاونی (Coop Admin):** مدیریت اعضا، تعریف واحدها و بلوک‌ها، صدور برنامه اقساط، تایید یا رد فیش‌های واریزی دستی، انتشار اطلاعیه تعاونی خود.
3. **عضو تعاونی (Member):** مشاهده مشخصات واحد اختصاص‌یافته، جدول سررسید اقساط، پرداخت آنلاین از طریق درگاه ساندباکس، بارگذاری فیش واریز، پیگیری وضعیت تایید فیش و مشاهده اطلاعیه‌ها.

---

## ۲. ساختار مدل داده (۱۰ جدول اصلی)
طراحی پایگاه‌داده به گونه‌ای است که اصل جداسازی اطلاعات تعاونی‌ها (Multi-Tenancy) در لایه داده تضمین شود:

| شماره | نام جدول | شرح عملکرد | کلیدهای خارجی |
|:---:|:---|:---|:---|
| ۱ | `users` | اطلاعات هویتی (شماره موبایل، نام، کد ملی ۱۰ رقمی با فرمول Mod 11) | - |
| ۲ | `cooperatives` | مشخصات تعاونی، عنوان پروژه، تعداد واحدها و حساب بانکی شبا | - |
| ۳ | `memberships` | پیوند چند-به-چند کاربر با تعاونی همراه با نقش (SUPER_ADMIN, COOP_ADMIN, MEMBER) | `user_id`, `cooperative_id` |
| ۴ | `units` | مشخصات فیزیکی واحدهای مسکونی (شماره، بلوک، طبقه، متراژ، پارکینگ، انباری) | `cooperative_id`, `assigned_member_id` |
| ۵ | `installment_plans` | سرفصل قرارداد مالی ساخت برای هر واحد و سقف برآورد ریالی | `cooperative_id`, `unit_id`, `member_id` |
| ۶ | `installment_items` | مواعید سررسید اقساط بر حسب مراحل ساخت (زمین، اسکلت، سفت‌کاری، نازک‌کاری) | `plan_id`, `cooperative_id` |
| ۷ | `payments` | تراکنش‌های مالی آنلاین ساندباکس و واریزهای دستی فیش بانکی | `cooperative_id`, `member_id`, `installment_item_id` |
| ۸ | `receipts` | اسناد و فیش‌های بانکی بارگذاری‌شده با ارجاع ۱ به ۱ به پرداخت | `payment_id`, `cooperative_id`, `reviewed_by` |
| ۹ | `announcements` | تابلوی اعلانات (سراسری مدیر کل با `cooperative_id = null` یا تعاونی خاص) | `cooperative_id`, `author_id` |
| ۱۰ | `audit_logs` | دفترکل رویدادنگاری تغییرناپذیر کلیه تراکنش‌ها، ممیزی و تایید/رد فیش‌ها | `cooperative_id`, `user_id` |

## ۳. قوانین و الزامات فنی رعایت‌شده
* **پایگاه‌داده PostgreSQL (سازگار با Supabase):** جداول ۱۱ گانه با پشتیبانی از کلاینت رسمی `@supabase/supabase-js` و متغیرهای `VITE_SUPABASE_URL` و `VITE_SUPABASE_ANON_KEY`.
* **هزینه‌های جاری و ماهانه مسکن (Monthly Fees):** ثبت و دریافت شارژ ماهانه، نگهداری آسانسور، سرایداری و قبوض مشترک مستقل از مراحل ساخت.
* **صدور گروهی هزینه/شارژ (Bulk Issuance):** امکان صدور همزمان شارژ یا هزینه برای کلیه اعضا یا اعضای دارای واحد مسکونی به صورت یکجا با یک کلیک.
* **ثبت مستقیم پرداخت توسط مدیر تعاونی:** امکان تسویه نقدی/پوز یا ثبت واریزی توسط مدیر به نیابت از عضو با تغییر وضعیت فوری به `PAID` و ثبت در لاگ.
* **محاسبات مالی ریالی:** ذخیره مبالغ به صورت عدد صحیح (`BIGINT`) در ریال، بدون استفاده از ممیز شناور جهت جلوگیری از اتلاف حتی یک ریال.
* **تفکیک چندمستأجری در لایه سرور:** هر کوئری بر اساس `cooperative_id` و کانتکست کاربر فیلتر شده و دسترسی عضو فقط به سطرهای خودش محدود است.
* **کنترل رسیدهای واریزی:** حداکثر حجم فایل ۲ مگابایت، اعتبارسنجی نوع فایل (`image/jpeg`, `image/png`, `application/pdf`).
* **بومی‌سازی کامل:** فونت وزیرمتن، چیدمان راست‌به‌چپ (RTL)، نمایش مبالغ و تاریخ‌ها به ارقام فارسی و تقویم شمسی جلالی.
* **الگوریتم‌های هویتی ایران:** اعتبارسنجی دقیق کد ملی با روش Mod 11 و شماره موبایل با الگوی ۰۹.

## ۴. داده‌های آزمایشی اولیه (Seed Data)
سیستم دارای داده‌های اولیه شامل:
* **۳ تعاونی مستقل:**
  1. تعاونی مسکن فرهنگیان منطقه ۵ (پروژه مروارید چیتگر - ۴۸ واحد)
  2. تعاونی مسکن کادر درمان بیمارستان رازی (پروژه یاسمن الهیه - ۶۴ واحد)
  3. تعاونی مسکن کارکنان گروه صنعتی پارس (پروژه البرز فردیس - ۱۲۰ واحد)
* **۱۴ کاربر و عضویت:** ۱ مدیر کل، ۳ مدیر تعاونی و ۱۰ عضو با کدهای ملی واقعی و واحدهای تخصیص‌یافته.
* برنامه‌های اقساط، پرداختی‌های آنلاین، فیش‌های بانکی، اطلاعیه‌ها و لاگ‌های حسابرسی.

## ۵. راه‌اندازی پایگاه داده (Supabase یا PostgreSQL محلی / سرور اختصاصی)

### الف) راه‌اندازی در Supabase (در ۳ مرحله):
1. در داشبورد [Supabase](https://supabase.com/dashboard) یک پروژه جدید ایجاد کنید.
2. کلیدهای پروژه را در فایل `.env` قرار دهید:
   ```env
   VITE_SUPABASE_URL="https://your-project.supabase.co"
   VITE_SUPABASE_ANON_KEY="eyJhbGci..."
   ```
3. وارد منوی **SQL Editor** در داشبورد Supabase شده، محتوای فایل `src/db/complete_migration.sql` را در آن پیست کرده و دکمه **RUN** را بزنید. تمام ۱۱ جدول با تنظیمات RLS و داده‌های اولیه ایجاد می‌شوند.

---

### ب) مهاجرت به PostgreSQL محلی یا سرور اختصاصی (Local Docker / Linux VPS):
معماری دیتابیس مسکن‌یار ۱۰۰٪ با PostgreSQL استاندارد سازگار است و هیچ وابستگی انحصاری (Vendor Lock-in) به Supabase ندارد:

1. **با Docker Compose (راه‌اندازی با ۱ دستور):**
   ```bash
   docker compose up -d
   ```
   دیتابیس PostgreSQL روی پورت `5432` و پنل مدیریت pgAdmin روی پورت `5050` اجرا می‌شود و جداول خودکار ساخته می‌شوند.

2. **با اسکریپت CLI خودکار:**
   ```bash
   # اجرای مهاجرت مستقیم روی هر پایگاه داده PostgreSQL:
   DATABASE_URL="postgres://postgres:maskanyar_secret_password@localhost:5432/maskanyar" npm run db:migrate
   ```

3. **با دستور کلاسیک psql:**
   ```bash
   psql -h localhost -U postgres -d maskanyar -f src/db/complete_migration.sql
   ```
